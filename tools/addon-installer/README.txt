ForeverBots add-on installer
============================
Double-click Install-Addon.cmd. It finds your WoW Forever game folder (the one with the file .build.info; it asks you to confirm),
copies the ForeverBots and ForeverDots add-ons into <game folder>\_forever_\Interface\AddOns (or _classic_beta_ on a beta-only
install), and tells you what to tick in the game. Each add-on folder is replaced by a clean copy, and old copies beside it
(ForeverBots.bak and the like) are removed. Run it again after a new release to refresh the add-ons. No administrator rights are
needed, and it does not touch any server.

By hand instead: put the folders ForeverBots and ForeverDots into <game folder>\_forever_\Interface\AddOns so that
...\AddOns\ForeverBots\ForeverBots.toc and ...\AddOns\ForeverDots\ForeverDots.toc exist.
