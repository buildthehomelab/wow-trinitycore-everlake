## Notes on Karrz's code (taken as is, for later or for Karrz)

- Darkmoon Faire re-dating (`GameEventMgr.cpp`, the new block in `Update`): if the client's Holidays date list has no later date,
  `SetHolidayEventTime` leaves `start` as it is, so the block runs again on every update and the Faire falls back to its
  `occurence` period (drift) without a warning. No loop or crash.
- Sitting on a chair (`GameObject::Use`) looks for the fire from where the player stood before the seat teleport is acknowledged,
  so a bench at the edge of a fire's range may or may not start the rest.
- `.playerbot campprobe <player> sit <quest>` removes the quest from the player's rewarded quests (GM only, but it changes data).
- `TextByLang` (`BotLanguage.cpp`) holds two languages in fixed arrays; a third `Lang` value would overrun them.
- The Windfury double proc in Karrz's own tree (see "Left out on purpose").
- Our #325 bindings stay off only while `2026_11_08_00` is unchanged: editing it would make the updater run it again after
  `2026_11_12_50_world_karrz_0135_imbue_owner` and bind the imbue scripts again.
